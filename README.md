## ✨ Features

- **WebGL Shader Canvas Background**: Real-time GPU ambient lighting shader responding to time and pointer movement.
- **Dual Magnetic Custom Cursor**: Fluid lag tracking with hover expansion states.
- **3D Certificate Stack Deck**: Skewed 3D card deck stack (`skewY(-6deg)` translate offset deck) with champagne sheen lift and Lightbox credential modal.
- **Interactive Project Simulators**:
  - **Tractor PTO & Drawbar Telemetry Analyzer**: Real-time RPM telemetry slider updating PTO HP, drawbar pull, fuel consumption, and wheel slip based on CFMTTI Budhni protocols.
  - **3D Agro-Machinery Animation Suite**: Drag-to-rotate interactive 3D CAD canvas simulator.
  - **Millet Agro-Processing Yield Engine**: Real-time millet de-hulling yield calculator based on ICAR-IIMR parameters.
  - **AI Crop & Machinery Diagnostic Simulator**: Predictive maintenance & crop health diagnostic simulator.
- **Web Audio API Synth**: Native UI sound feedback generator with navbar sound toggle (`SOUND ON / MUTED`).
- **Interactive Skill Filters**: Filter cards by category (`Machinery & AgTech`, `3D Design & AutoCAD`, `Web & AI Tech`, `Core & Languages`).

## 🛠️ How to Deploy to GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com/new) and create a new repository named `portfolio` (or `<your-username>.github.io`).

2. **Push your code to GitHub**:
   Run the following commands in your terminal:
   ```bash
   git add .
   git commit -m "Initial commit of interactive AgTech portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_GITHUB_USERNAME/portfolio.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select **Deploy from a branch**.
   - Select `main` branch and `/ (root)` folder, then click **Save**.
   - In 1-2 minutes, your live portfolio link will be active at:
     `https://YOUR_GITHUB_USERNAME.github.io/portfolio`
